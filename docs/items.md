# Items and recipes

## Share an item

Open an item and copy the address from the browser. For example, `/server/universum/items/minecraft%3Adiamond` opens the diamond's recipe panel. The link can also carry the selected recipe view, station, page, and ingredient group. Existing links such as `#/server/universum/items?item=minecraft%3Adiamond` still open the same item, including legacy links that open over Players or server Home.

The Node service uses the published catalog to send the item name, a description, and Open Graph metadata in the initial HTML. Browsers with JavaScript show the scene loader until the app opens the item. With JavaScript disabled, the page shows a basic item summary and a link to the catalog. The service makes a square PNG preview from the imported item icon, preserving transparency and using nearest-neighbor scaling. Items without an imported icon use the Capycraft favicon. The public item URL stays the same across imports.

`/sitemap.xml` lists the sitemap files for published catalogs. Each file includes up to 25,000 canonical item URLs, and `/robots.txt` points crawlers to the index. The sitemap uses the current catalog manifests, so publishing an update refreshes the listed items independently of the site build.

The Node service also sends Open Graph titles and descriptions for the home page, server overview, Items, Players, Achievements, Quests, and player profiles. These pages use the existing Capycraft favicon as their shared preview image. Browser tab titles follow in-app navigation, including when an item detail is closed.

See [Caddy routes](deployment.md#caddy-routes) for the production handlers. Caddy's forwarded scheme and the request host determine the absolute URLs in page metadata and sitemaps.

## Browse and search

Select a server and open **Items** (for example `/server/universum/items`). The [catalog](../src/items/ItemCatalog.tsx) loads a small manifest and a JSON response for each page of up to 100 items. Search uses exported names and registry IDs. Use `@mod` for a mod namespace, `#tag` for an exported recipe tag, or `$text` for text in the default tooltip. Combine terms with spaces and put phrases in quotes. The mod filter lists all namespaces and narrows the list as you type. Selecting a mod adds its namespace to the search field. Choosing **All mods** removes all mod terms and keeps the rest of the search. The search service returns one page of matching items.

Names use the Minecraft client's language at export time. The catalog shows a language notice on the first visit after each page load. Select the checkbox to hide it on future visits in that browser.

### Paging and loading

The grid requests previews for visible slots concurrently and requests more as they scroll into view. The page arrows and mouse wheel at a scroll boundary keep the current grid visible while the target page and its previews load. The next grid appears all at once, including on narrow screens. A loading indicator floats over the grid during longer waits. The field between the arrows shows the selected page beside the total. Enter a page number and press Enter to jump to it. The URL query records the search text and page number so reloading restores the same search results. Repeated navigation uses the latest chosen page, including while previews are loading. After a short pause in navigation input, the catalog requests the latest target and cancels superseded requests. Import progress floats below the header. When a revision finishes publishing, the open catalog loads it while keeping the search and page. On short screens, slots shrink to fit where space allows. When the grid still needs to scroll, it scrolls independently of the filters and pagination. Hover over a slot or focus it with the keyboard to see its [in-game tooltip](../src/items/ItemTooltip.tsx) with exported text styles. The catalog reuses one tooltip panel as you move between slots. The item name appears immediately, with a loading indicator if the exported text is slow to arrive.

The pinned tooltip offers the actions and tooltip shortcuts available for that item. The **F3 + H** button toggles advanced item information across the site, including item IDs and available durability. The browser remembers the setting until you turn it off. Item-specific tooltip shortcuts apply to the open panel and reset when it closes. When a server's published Ponder scene is associated with an item, choose **Ponder** or press its displayed shortcut to open the player in a dialog. If more than one scene matches, select a scene in the dialog. When WebCraft exports an inventory bar, the catalog draws its track and colored fill on the item preview, including a visible empty track for a bar with zero fill.

## Recipes and ingredient options

Click or tap an item once to pin its tooltip. Activate the same slot again to open its production recipes. The question mark beside Close describes the gestures for the current input device. For an ingredient group, the second activation opens the list of variants. Activate a different slot to pin its tooltip. Select and copy text in the pinned tooltip. Click or tap outside or press **Escape** to dismiss it. Right-click or touch and hold an item to open recipes that list it as an ingredient. A progress indicator appears while holding. The importer indexes concrete ingredient IDs for the uses view. The API can build the index on the first request for an existing catalog revision. Results can be partial when the exporter supplies only examples or a recipe result.

### Recipe layouts

Recipes open beside the catalog on screens at least 68 rem wide. On narrower screens and when opening a recipe from another page, they open in a dialog. The recipes scroll beneath the heading and close button. They are grouped into tabs by station, with result-only entries in **Other**. Station tabs show a catalog preview where available and a name otherwise. The station tabs stay in a single row. When the row overflows, the arrows scroll by one tab at a time. Crafting table recipes show all nine slots for patterns that fit the 3 × 3 grid. Shaped inputs keep their row and column positions, and shapeless inputs fill the grid in export order. Machine recipes trim the unused space around their exported slots and scale item icons to the crafting grid size where the available width allows. Each station shows up to three recipes per page, with arrows when more recipes are available. Recipe cards fit their contents, and the dialog retains its size across tabs and pages. Select the station icon to see how to craft that station.

### Ingredient variants

Hover or focus an ingredient or result for its tooltip. Ingredient groups rotate available previews every two seconds. Rotation pauses while the pointer is over any recipe slot, including empty slots, or while an ingredient group is focused or its tooltip is open. Reduced motion keeps the preview still. An ingredient with one known complete match uses that item's tooltip and links straight to it. Tagged ingredient groups show a **#** marker. Open an ingredient group to see its exported tag names and a paginated grid of ingredient variants. Hover or focus a slot for its name and details. Right-click a displayed ingredient to see recipes that use it. The importer combines all members of tags included in the archive with explicitly listed ingredients. If the export supplies only a capped set of examples, the dialog marks the list as incomplete. To restore tag members omitted by an older import, reimport an archive that contains the full tag lists. Following a recipe link replaces the displayed item. Closing the recipe dialog returns to the underlying page. With advanced item information enabled, the recipe detail lets you select a stack variant and expand its NBT and components when available.

### Recipe URLs

Recipe links belong to a server instance and can open over its Items page, Players page, or server home. For example, `/server/atm10/items/minecraft%3Achest?from=players` opens the chest recipe over Players. The named `view=uses` and `ingredient` options can appear in any order. Opening a group adds its recipe ID and input slot to the URL so the link restores both dialogs. Closing that group returns to the recipe. Earlier item detail links still work, and links without a server alias open the default server. Keep the original ZIP private and only import exports whose item information is intended for public display.
